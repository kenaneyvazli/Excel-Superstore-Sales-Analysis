# 📊 US Superstore Sales & Performance Dashboard (MS Excel)

## 📌 Project Overview
This project features an interactive **MS Excel Dashboard** designed to analyze sales performance, category distribution, customer segments, and regional trends for a retail Superstore.

The goal is to transform raw transactional data into actionable business insights using Advanced Excel techniques, Data Modeling, and Dynamic Visualizations.

---

## 🔑 Key Features & Insights
- **KPI Metrics:** Total Sales volume ($2.26M) and Total Orders count (9,800).
- **Regional Analysis:** Sales breakdown by geographic regions to identify top-performing areas.
- **Product Category Distribution:** Revenue contributions across Product Categories (Technology, Office Supplies, Furniture).
- **Dynamic Slicers:** Interactive filters for *Ship Mode* and *Segment* linked across Pivot Tables.

---

## 🛠 Tools & Techniques Used
- **Microsoft Excel:** Pivot Tables, Pivot Charts, Slicers, Report Connections
- **Dashboard Design:** Clean layout, structured KPI cards, consistent color palette, and dynamic gridlines handling.
